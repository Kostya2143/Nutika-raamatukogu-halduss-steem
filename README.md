# Raamatukogu Haldussüsteem

Lihtne Pythonis kirjutatud raamatukogu haldussüsteem.

## Funktsioonid

* Raamatute lisamine
* Raamatute kuvamine
* Kasutajate lisamine
* Raamatute laenutamine
* Raamatute tagastamine
* Andmete salvestamine CSV-failidesse

## Kasutatud tehnoloogiad

* Python 3
* CSV
* OS
* Datetime

## Käivitamine

```bash
python main.py
```

## Failid

* `raamatud.csv` – raamatute andmed
* `kasutajad.csv` – kasutajate andmed
* `laenutused.csv` – laenutuste andmed
